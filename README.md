# Арканоїд для Android

Лабораторна робота №3 з ООП. Гра «Арканоїд» під Android на Java з сенсорним
керуванням, трьома рівнями складності, логуванням через `java.util.logging` та
підтримкою англійської й української мов.

Використано лише Android SDK і стандартну бібліотеку Java — без AndroidX та
сторонніх залежностей (JUnit 4 — тільки для тестів).

## Гра

- Платформа рухається за пальцем, відпускання пальця запускає м'яч.
- Кут відбиття залежить від того, в яку частину платформи влучив м'яч.
- Після кожного влучання в цеглинку м'яч трохи пришвидшується.
- Три рівні з різним розташуванням цеглинок. Колір цеглинки показує, скільки
  ударів вона ще витримає; сірі цеглинки незруйновні.
- Пауза — кнопка у правому верхньому куті. Коли застосунок згортається, гра
  автоматично ставиться на паузу.
- Найкращий результат зберігається окремо для кожного рівня складності.

| Складність | Швидкість м'яча | Ширина платформи | Життя | Міцність цеглинок | Множник очок |
|------------|-----------------|------------------|-------|-------------------|--------------|
| Легко      | 620             | 26 % поля        | 5     | як у рівні        | ×1           |
| Нормально  | 820             | 20 % поля        | 3     | як у рівні        | ×2           |
| Складно    | 1020            | 15 % поля        | 2     | +1 удар           | ×3           |

Рівні описані рядками в `Levels`: цифра — кількість ударів, `#` — незруйновна
цеглинка, `.` — порожня клітинка.

## Структура

- `game` — логіка гри без залежностей від Android: `GameWorld` (фізика,
  зіткнення, стани гри), `Ball`, `Paddle`, `Brick`, `Levels`, `Difficulty`,
  `GameState`. Світ має фіксований розмір 900×1600 умовних одиниць, а `GameView`
  масштабує його під екран.
- `ui` — `MenuActivity` (вибір складності, рекорд, мова), `GameActivity`
  (повноекранний режим) і `GameView` (`SurfaceView` з окремим ігровим потоком).
- `data` — `GamePrefs`: налаштування та рекорди у `SharedPreferences`.
- `log` — налаштування логера.
- `i18n` — перемикання мови застосунку.

## Логування

Використовується `java.util.logging`. `ArkanoidApp` під час запуску викликає
`LoggingConfig`, який:

- читає рівні з `app/src/main/assets/logging.properties`;
- прибирає стандартний обробник і додає `LogcatHandler`, що передає записи в
  Logcat з тегом `Arkanoid` (`SEVERE` → `E`, `WARNING` → `W`, `INFO` → `I`,
  `CONFIG`/`FINE` → `D`, нижче → `V`);
- додає `FileHandler` з ротацією (3 файли по 256 КБ) у
  `files/logs/arkanoid*.log` із форматом `LineFormatter`;
- у release-збірці підвищує рівень логера застосунку до `INFO`.

Також логуються необроблені винятки.

```
adb logcat -s Arkanoid
adb shell run-as com.dagen.arkanoid cat files/logs/arkanoid0.log
```

## Локалізація

- Рядки винесено в ресурси: `values/strings.xml` (англійська, мова за
  замовчуванням) і `values-uk/strings.xml` (українська).
- Для кількості життів використано `plurals` з формами `one`/`few`/`many`/`other`
  («1 життя», «2 життя», «5 життів»).
- Числа форматуються через `NumberFormat` з урахуванням локалі (`12,340` /
  `12 340`).
- Мову можна змінити в меню: «Як у системі», English або Українська. Вибір
  зберігається, а `BaseActivity` застосовує його через `attachBaseContext`.
- Розбиття App Bundle за мовами вимкнено, щоб усі переклади були в APK.

## Збірка та запуск

Потрібні JDK 17+ і Android SDK (platform 37). Шлях до SDK вказується в
`local.properties` (`sdk.dir=...`) або змінною `ANDROID_HOME`.

```
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

Або відкрити проєкт в Android Studio і запустити конфігурацію `app`.

## Тести

```
./gradlew testDebugUnitTest
```

Модульні тести перевіряють логіку гри (відбиття від стін і платформи, руйнування
цеглинок, втрату життів, перехід між рівнями, перемогу, паузу), параметри
складності, коректність рівнів і форматування логів.
